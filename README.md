1. Vertical vs. Horizontal Software Packages

Vertical software packages assist users within a specific, specialised industry. They are designed to meet the needs of a particular type of business.

Example: Hospital inventory management software is used by hospitals to track medical supplies and manage stock.

Horizontal software packages perform general functions across a wide range of different businesses.

Example: Microsoft Excel is used by different businesses to organise data, perform calculations, and create reports.


Vertical software focuses on a specific industry, while horizontal software performs general functions that can be used by different businesses and industries.

2. Operating System Modes

Batch processing is the processing of programs or transactions in batches without user interaction.

Business example: A company processes employee salaries together at the end of the month using a payroll system.

Real-time processing refers to systems that respond to an event within a fixed time interval.

Industrial example: A manufacturing plant uses real-time processing to monitor equipment and respond to changes in operating conditions within the required time.


Batch processing handles programs or transactions in groups without user interaction. Real-time processing responds to events within a fixed time interval. Batch processing is suitable for monthly payroll, while real-time processing is suitable for manufacturing equipment monitoring.
